# История изменений

## 0.5.0 — 6 октября 2026

- **Модуль WEEEK CRM:**
  - Получение списка воронок (`weeek_list_funnels`) и этапов воронки (`weeek_list_funnel_statuses`).
  - Создание сделки с верификацией (`weeek_create_deal`, обязательный `confirm: true`).
  - Детальное чтение и пагинированный список сделок (`weeek_get_deal`, `weeek_list_deals`).
  - Обновление полей сделки, суммы и статусов (`weeek_update_deal`).
  - Перенос сделки по этапам воронки (`weeek_set_deal_status`).
  - Аналитическая сводка по воронкам (`weeek_crm_summary`).
- **Расширенные рабочие процессы задач:**
  - Перемещение задачи по колонкам доски (`weeek_set_task_status`).
  - Добавление и пагинированное чтение комментариев в Markdown (`weeek_add_task_comment`, `weeek_list_task_comments`).
  - Управление ответственными по имени или ID (`weeek_change_task_assignees`).
  - Управление иерархией подзадач (`weeek_set_task_parent`).
  - Поддержка нативных дат начала и дедлайнов (`startDate`, `dueDate`).
- **Контроль контракта и качество:**
  - Добавлена матрица соответствия 157 операций WEEEK OpenAPI (`docs/API-MATRIX.md`).
  - Добавлена дорожная карта реализации оставшихся сущностей (`docs/ROADMAP.md`).
  - Добавлена автоматическая утилита отслеживания дрейфа API (`npm run api:check`).
  - Набор автоматических тестов расширен до 151 теста (все сценарии и обработка ошибок).
  - Настроен безопасный сценарий живой приёмки (`scripts/live-acceptance.mjs`).
  - Обновлен runtime MCP SDK до актуальной стабильной версии.
